| TD-R01                                    | `next build` failed on `/404`/`/_not-found` with `Error: <Html> should not be imported outside of pages/_document` (or, intermittently, `TypeError: Cannot read properties of null (reading 'useContext')`). Root cause: `apps/web`/`apps/admin`'s `build`/`dev`/`start` scripts wrapped Next.js commands in `dotenv -e ../../.env --` to load the shared root `.env`, which contained `NODE_ENV=development`. dotenv-cli injected that into the child process _before_ Next.js's own bootstrap ran, so Next's internal `process.env.NODE_ENV \|\| "production"` default-setting logic never fired — the entire production build then ran with `NODE_ENV=development`, causing a mismatch between Next's production-compiled internals (`pages.runtime.prod.js`) and the development build of `react-dom-server.edge.development.js`, which trips an internal cross-realm sanity check.
