## Assumptions

| #    | Assumption                                                                                                                                                 | Risk if Wrong                                                                                            | Owner to Confirm                |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------- |
| A-01 | Target users are primarily under-18 exam aspirants (12th grade / UG entrance), so guardian-consent and India-specific data-handling (DPDP Act) apply       | Consent/legal flows built now may need rework if the user base skews differently                         | Product Owner                   |
| A-02 | Single-tenant B2C platform (not white-labeled/multi-tenant)                                                                                                | Multi-tenancy would require schema-level changes (tenant_id) not currently planned                       | Product Owner                   |
| A-03 | Native mobile app is out of scope through at least Phase 5 (PRD-01 §9 non-goal)                                                                            | Mobile Push adapter is stubbed, not built; would need to be prioritized earlier if this changes          | Product Owner                   |
| A-04 | Postgres native full-text search (tsvector) is sufficient at MVP scale; no dedicated search engine (Elasticsearch/Meilisearch) needed yet                  | Content/college/article search UX may be weaker than a dedicated engine until reconsidered               | Engineering, revisit at Phase 4 |
| A-05 | Question bank, creative briefs, articles and all learning content are originally authored/licensed — no content sourced from `/screens` or any third party | Legal/IP risk if content sourcing deviates from this                                                     | Product Owner / Content team    |
| A-06 | Docker Desktop / Docker Engine is available in every developer and CI environment for local Postgres/Redis/MinIO                                           | Local dev instructions in Sprint 0 assume this; document a cloud-hosted fallback if not universally true | Engineering                     |
| A-07 | Razorpay is confirmed (not a default) as the payment gateway per SRS-02/PRD-01                                                                             | None — this is a stated requirement, not a guess                                                         | Confirmed                       |
| A-08 | "Physical DB design governs over logical design" (MDG-00 §2) means DB-34 wins wherever DB-05/DB-16 disagree on table/column details                        | Schema decisions should always check DB-34 first                                                         | Engineering                     |
